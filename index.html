        01 · Minimum moves
        
          
        Why is the minimum 2ⁿ − 1?
        
          
        
            To move the biggest disk, all n − 1 smaller disks must first be moved out of the way,
            and afterwards moved back on top of it. So the moves needed are
            T(n) = 2 · T(n − 1) + 1, with T(1) = 1. Solving this gives T(n) = 2ⁿ − 1:
            1, 3, 7, 15, 31 … Each extra disk doubles the work, so the time complexity is O(2ⁿ).

        02 · Data structure
        
          
        Every peg is a Stack
        
          
        
            Each peg only lets you touch its top disk, exactly like a stack: Last In, First Out.
            Moving a disk is two stack operations: pop() from the source peg, then push() onto
            the target peg. peek() lets us check the top disk before moving, so we can block a
            larger disk from landing on a smaller one. All three operations take O(1) time.
          
        
        
        

        
        
          
        03 · Recursion
        
          
        Breaking the problem into sub-towers
        
          
        
            To move a tower of n disks from A to C: (1) move the top n − 1 disks from A to B,
            using C as the spare; (2) move the biggest disk from A to C; (3) move the n − 1 disks
            from B to C, using A as the spare. Steps 1 and 3 are the same puzzle with one fewer
            disk — that is recursion. The smallest case, one disk, is moved directly.
